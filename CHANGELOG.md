# Changelog

## 0.3.0 - 2026-11-13 - P3 playable prototype
- New Godot playable entry scene: three increasing top-down mazes and parkour levels.
- Procedural maze generation, pickup keys, stage doors, dog AI, collisions and three hearts.
- Three kittens collectible only at the ends of parkour; each rescued kitten returns to the mother before next round.
- Larger touch controls and keyboard controls; jump/checkpoints and pause.
- Short synthetic kitten meows and dog barks triggered by actual events, audio toggle.
- Android export preset, CI build and regression script.
- Android APK availability is conditional on a successful Actions build; on-device QA pending.

## 0.2.0 - 2026-11-13
- Added 34 platformer graphics and a 16-tile Godot TileSet with collision.
- Added 11 reusable platform scenes, backdrop and platformer asset review.
- Validated documented terrain seams; removed detached source fragments.
- Included the complete 0.1 character, maze, UI and audio assets.
- Added import checks, collision checks, provenance and Polish instructions.

## 0.1.0
Initial generated prototype assets, animation review and synthesized sounds.
